# 🎓 InternCoach AI — AI-Powered Resume Coach for Internship Applications

> An AI-powered resume feedback tool that delivers structured critique and keyword analysis to help students land internships — built with React, Vite, and AI API integration.

---

## 📋 Overview

InternCoach AI takes the guesswork out of resume writing. Paste in your resume and a target job description, and the app returns structured, actionable feedback — including keyword gap analysis, clarity suggestions, and section-by-section coaching.

Built specifically for internship applicants who want to tailor resumes quickly and effectively.

---

## ✨ Features

- 🤖 **AI Feedback Engine** — Delivers fast, structured resume critique via AI API integration
- 🔑 **Keyword Analysis** — Identifies missing keywords from the job description to improve ATS performance
- 📝 **Structured Feedback** — Organized feedback by resume section (Summary, Experience, Skills, etc.)
- 🎯 **Internship-Focused** — Prompts and analysis tuned specifically for entry-level and internship roles

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) installed
- npm

### Installation

```bash
git clone https://github.com/eshaunsimons62-hue/InternCoach-AI.git
cd InternCoach-AI
npm install
npm run dev
```

The app will be running at `http://localhost:5173`

## 💡 How It Works

1. **Input** — Paste your resume and the target job description
2. **Keyword Extraction** — The tool identifies key skills and terms from the job posting
3. **AI Analysis** — The model evaluates your resume against the job requirements
4. **Structured Output** — Returns feedback organized by category:
   - Missing keywords
   - Weak action verbs
   - Quantification opportunities
   - Section-specific suggestions
